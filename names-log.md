# Province names log

Method: each region is fixed as a block. Modern hidden name (field 10) and the town list (field 6) locate the hex; names come from the language of the people recorded there, attested toponyms first, then regional river/mountain/people names, then a compound built from documented vocabulary of that language and matched to the hex's real feature (lake, creek, river, island, hill, bay, rapids).

## Alberta – Saskatchewan boreal/prairie (2026-11-01)

- Provinces renamed: 508 (502 in the main pass, 6 follow-ups).
- Attested: 1 (`Sahtú Deh`).
- Built: 507.
- Languages: Cree (Plains/Woods), Dene (northern Alberta outliers).
- Why built: nearly all these hexes are unnamed lakes, creeks, islands and hills whose only recorded toponym is a colonial English/French name (Cassiar Land District, Hythe, Larne Creek, Steen River...). No attested indigenous name survives for the individual micro-feature, so names were built from documented Cree/Dene vocabulary and matched to the feature type in field 10.
- Checks: no name repeated more than 3 times in the region, no 1–2 letter names, no placeholders, no colonial words.
- Follow-ups: 4 duplicate `Dene Pēnakamik`/`Oka Anompa` and 2 two-letter `tu` hexes replaced.
